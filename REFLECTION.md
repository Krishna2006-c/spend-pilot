# Reflection

Building AI Spend Audit helped improve my understanding of full-stack SaaS development using Next.js, Supabase, and Vercel.

Main learnings:

- Building dynamic React dashboards
- Managing application state
- Creating reusable audit logic
- Integrating Supabase databases
- Handling production deployments
- Managing environment variables
- Debugging deployment issues

Challenges faced:

- Supabase environment variable setup
- Vercel deployment configuration
- Recommendation engine logic
- Hydration mismatch issues

This project improved both frontend and backend development skills.
